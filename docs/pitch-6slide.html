Slide 3

Technical approach & prototype

2:09 → 3:27
SANKETtechnical approach 100 words · 40 sec

So how does Bhoomi3D actually work?

The pipeline is: input, ground and structure separation, building detection, floor detection, 3D volume generation, identity, validation, viewer.

For LiDAR, the system separates ground from structures and finds the building geometry. For a 2D plan, it reads the footprint and floor information directly.

Each floor is then assigned its vertical position and height.

And this is the key step. A polygon alone gives a flat shape. Polygon, plus Z-level, plus height — gives a 3D property volume.

Each volume receives its own identifier. Then validation checks for overlaps, clearance violations and containment errors.

On the slide — not spoken

  • The eight-stage pipeline as a horizontal chain
  • The Polygon → Polygon+Z+Height comparison, drawn
  • Tech stack, small, in a corner: Python · FastAPI · NumPy · SciPy · Shapely · laspy · rasterio · WebGL2 offline viewer

So what changes when property becomes three-dimensional?

For a citizen — buying a flat becomes safer. You can see the exact volume you are purchasing, not just a flat number on paper.
